# Mathematics Formulae & Short Tricks --- Competitive Exams

> **Purpose:** Quick revision for competitive and recruitment
> examinations.\
> **How to use:** Memorize the formulae first, then practice the short
> tricks with timed questions.

------------------------------------------------------------------------

## 1. Number System

### Basic Formulae

-   For two positive integers:
    -   **HCF × LCM = Product of the two numbers**
-   If `a = bq + r`, then:
    -   `0 ≤ r < b`
-   Sum of first `n` natural numbers:
    -   `n(n+1)/2`
-   Sum of first `n` even numbers:
    -   `n(n+1)`
-   Sum of first `n` odd numbers:
    -   `n²`
-   Sum of squares:
    -   `n(n+1)(2n+1)/6`
-   Sum of cubes:
    -   `[n(n+1)/2]²`

### Divisibility Rules

-   **2:** Last digit is even.
-   **3:** Sum of digits divisible by 3.
-   **4:** Last two digits divisible by 4.
-   **5:** Last digit is 0 or 5.
-   **6:** Divisible by both 2 and 3.
-   **8:** Last three digits divisible by 8.
-   **9:** Sum of digits divisible by 9.
-   **10:** Last digit is 0.
-   **11:** Difference between alternating digit sums is 0 or a multiple
    of 11.
-   **12:** Divisible by both 3 and 4.

### Quick Tricks

-   To check divisibility by **3 or 9**, repeatedly add digits.
-   For large products, use factorization before multiplication.
-   If numbers are close to a base such as 100:
    -   `98 × 97 = (100-2)(100-3) = 9506`

# 2. Simplification

### BODMAS

**B**rackets → **O**rders/Of → **D**ivision → **M**ultiplication →
**A**ddition → **S**ubtraction

### Useful Algebraic Identities

-   `(a+b)² = a² + 2ab + b²`
-   `(a-b)² = a² - 2ab + b²`
-   `a²-b² = (a-b)(a+b)`
-   `(a+b)³ = a³ + 3a²b + 3ab² + b³`
-   `(a-b)³ = a³ - 3a²b + 3ab² - b³`
-   `a³+b³ = (a+b)(a²-ab+b²)`
-   `a³-b³ = (a-b)(a²+ab+b²)`
-   `(a+b+c)² = a²+b²+c²+2(ab+bc+ca)`

### Fast Multiplication

For numbers near 100:

`(100-a)(100-b) = 10000 - 100(a+b) + ab`

Example:

`96 × 94 = (100-4)(100-6) = 9024`

For numbers near 50:

`(50+a)(50+b) = 2500 + 50(a+b) + ab`

-   `a/b - c/d = (ad-bc)/bd`

# 4. Percentage

### Basic Formula

`Percentage = (Part / Whole) × 100`

### Increase/Decrease

`Percentage change = (Change / Original) × 100`

### Successive Percentage Change

If changes are `a%` and `b%`:

`Net change = a + b + ab/100`

Use negative values for decreases.

Example:

Increase 20%, then decrease 10%:

`20 - 10 - (20×10)/100 = 8% increase`

### Important Trick

If a value increases by `x%`, the percentage decrease required to return
to the original is:

`100x / (100+x)%`

If a value decreases by `x%`, the percentage increase required to return
to the original is:

`100x / (100-x)%`

# 5. Ratio and Proportion

### Ratio

`a:b = a/b`

If `a:b = m:n`, then:

`a = km, b = kn`

### Proportion

`a:b = c:d`

Therefore:

`ad = bc`

### Fourth Proportional

For `a:b = c:x`:

`x = bc/a`

### Third Proportional

If `a:b = b:x`:

`x = b²/a`

### Direct Proportion

If `x ∝ y`:

`x/y = constant`

### Inverse Proportion

If `x ∝ 1/y`:

`xy = constant`

### Trick

When quantities are divided in a ratio, first calculate:

`Total parts = sum of ratio terms`

Then:

`One part = Total quantity / Total parts`

------------------------------------------------------------------------

# 6. Average

### Formula

`Average = Sum of observations / Number of observations`

Therefore:

`Sum = Average × Number`

### Combined Average

`Combined average = (n₁a₁+n₂a₂)/(n₁+n₂)`

### Replacement Trick

If one number `x` is replaced by `y` among `n` observations:

`New average = Old average + (y-x)/n`

### Quick Trick

For equally spaced numbers:

Average = middle number.

Example:

`11, 13, 15, 17, 19`

Average = `15`

------------------------------------------------------------------------

# 7. Profit, Loss and Discount

### Definitions

-   `Profit = SP - CP`
-   `Loss = CP - SP`
-   `Profit% = Profit/CP × 100`
-   `Loss% = Loss/CP × 100`

### Selling Price

At `p%` profit:

`SP = CP(100+p)/100`

At `p%` loss:

`SP = CP(100-p)/100`

### Discount

`Discount = MP - SP`

`Discount% = Discount/MP × 100`

`SP = MP(100-d)/100`

### Successive Discounts

For discounts `a%` and `b%`:

`Effective discount = a+b-ab/100`

### Trick

If CP and profit percentage are known, calculate SP directly.

Example:

CP = ₹500, profit = 20%

SP = `500 × 120/100 = ₹600`

------------------------------------------------------------------------

# 8. Simple Interest

### Formula

`SI = PRT/100`

Where:

-   `P` = Principal
-   `R` = Rate %
-   `T` = Time

### Amount

`A = P + SI`

### Important

For the same principal, rate and time:

`SI ∝ R × T`

### Trick

Convert months into years:

`6 months = 1/2 year`

`3 months = 1/4 year`

------------------------------------------------------------------------

# 9. Compound Interest

### Annual Compounding

`A = P(1+R/100)^T`

`CI = A-P`

### Half-Yearly Compounding

-   Rate = `R/2`
-   Time = `2T`

`A = P(1+R/200)^(2T)`

### Quarterly Compounding

-   Rate = `R/4`
-   Time = `4T`

### Difference Between CI and SI for 2 Years

`CI-SI = P(R/100)²`

### Trick

For 2 years:

`CI = P[2R/100 + R²/10000]`

------------------------------------------------------------------------

# 10. Time and Work

### Basic Concept

If A completes work in `x` days:

`A's one-day work = 1/x`

If B completes it in `y` days:

`B's one-day work = 1/y`

Together:

`1/x + 1/y`

### Two-Person Formula

If A takes `x` days and B takes `y` days:

`Together time = xy/(x+y)`

### Efficiency

`Efficiency ∝ 1/Time`

If A is twice as efficient as B:

`A:B efficiency = 2:1`

Therefore:

`A:B time = 1:2`

### LCM Method

For exam speed:

1.  Take LCM of individual times as total work.
2.  Calculate each person's daily work.
3.  Add daily work.
4.  Divide total work by combined daily work.

------------------------------------------------------------------------

# 11. Pipes and Cisterns

Treat filling as **positive work** and emptying as **negative work**.

If a pipe fills a tank in `x` hours:

`Rate = 1/x`

If an outlet empties it in `y` hours:

`Rate = -1/y`

Net rate:

`1/x - 1/y`

Time:

`1 / Net rate`

### Trick

Use the LCM method exactly like Time & Work.

------------------------------------------------------------------------

# 12. Time, Speed and Distance

### Core Formulae

`Speed = Distance/Time`

`Distance = Speed × Time`

`Time = Distance/Speed`

### Unit Conversion

`1 km/h = 5/18 m/s`

`1 m/s = 18/5 km/h`

### Average Speed

For equal distances at speeds `x` and `y`:

`Average speed = 2xy/(x+y)`

For equal time:

`Average speed = (x+y)/2`

### Relative Speed

Same direction:

`Relative speed = |x-y|`

Opposite direction:

`Relative speed = x+y`

------------------------------------------------------------------------

# 13. Trains

### Train Crossing a Pole

`Time = Train length / Speed`

### Train Crossing a Platform

`Time = (Train length + Platform length) / Speed`

### Two Trains

Opposite direction:

`Time = (L₁+L₂)/(S₁+S₂)`

Same direction:

`Time = (L₁+L₂)/|S₁-S₂|`

------------------------------------------------------------------------

# 14. Boats and Streams

Let:

-   Downstream speed = `D`
-   Upstream speed = `U`

### Formulas

`Speed of boat = (D+U)/2`

`Speed of stream = (D-U)/2`

### Trick

Downstream = boat + stream

Upstream = boat - stream

# 15. Mixture and Alligation

### Alligation Rule

For cheaper price `C`, dearer price `D`, mean price `M`:

`Cheaper : Dearer = (D-M):(M-C)`

### Example

Mix ₹20/kg and ₹30/kg to obtain ₹24/kg:

Ratio:

`(30-24):(24-20) = 6:4 = 3:2`

### Replacement

If `x` quantity is removed from a vessel of volume `V` and replaced
repeatedly:

Amount of original substance after `n` operations:

`Initial amount × (1-x/V)^n`

# 16. Partnership

Profit is divided in the ratio:

`Capital × Time`

If A invests `P₁` for `T₁` and B invests `P₂` for `T₂`:

`Profit ratio = P₁T₁ : P₂T₂`

### Trick

Always multiply **money × months** (or years) before forming the ratio.

# 17. Algebra

### Linear Equation

`ax+b=0`

`x=-b/a`

### Two Linear Equations

For:

`a₁x+b₁y=c₁`

`a₂x+b₂y=c₂`

Use elimination/cross multiplication.

### Quadratic Equation

For:

`ax²+bx+c=0`

Roots:

`x = [-b ± √(b²-4ac)]/(2a)`

### Nature of Roots

Discriminant:

`D = b²-4ac`

-   `D > 0` → two distinct real roots
-   `D = 0` → equal real roots
-   `D < 0` → no real roots

### Sum and Product of Roots

For `ax²+bx+c=0`:

`α+β = -b/a`

`αβ = c/a`

# 18. Indices and Surds

### Laws of Indices

-   `a^m × a^n = a^(m+n)`
-   `a^m/a^n = a^(m-n)`
-   `(a^m)^n = a^(mn)`
-   `a^0 = 1`
-   `a^-n = 1/a^n`
-   `a^(1/n) = ⁿ√a`

### Surd Trick

Rationalize:

`1/(√a+√b)`

Multiply by:

`(√a-√b)/(√a-√b)`

# 19. Geometry

## Lines and Angles

-   Straight angle = `180°`
-   Full angle = `360°`
-   Right angle = `90°`
-   Vertically opposite angles are equal.
-   Sum of angles on a straight line = `180°`

## Triangle

Sum of interior angles:

`180°`

Exterior angle:

`= Sum of two opposite interior angles`

### Area

`Area = 1/2 × base × height`

### Heron's Formula

For sides `a,b,c`:

`s = (a+b+c)/2`

`Area = √[s(s-a)(s-b)(s-c)]`

### Equilateral Triangle

Area:

`(√3/4)a²`

Height:

`(√3/2)a`

`base × height`

# 23. Permutation and Combination

### Factorial

`n! = n(n-1)(n-2)...1`

`0! = 1`

### Permutation

`nPr = n!/(n-r)!`

### Combination

`nCr = n!/[r!(n-r)!]`

### Important Identities

-   `nCr = nC(n-r)`
-   `nCr + nC(r-1) = (n+1)Cr`

### Trick

Use combinations when **selection** matters.

Use permutations when **arrangement/order** matters.

# 24. Probability

### Basic Formula

`P(E) = Favorable outcomes / Total outcomes`

### Range

`0 ≤ P(E) ≤ 1`

### Complement

`P(not E) = 1-P(E)`

### Addition Rule

For mutually exclusive events:

`P(A or B) = P(A)+P(B)`

General:

`P(A∪B)=P(A)+P(B)-P(A∩B)`

### Independent Events

`P(A∩B)=P(A)P(B)`

### Conditional Probability

`P(A|B)=P(A∩B)/P(B)`

### Trick

For "at least one":

`P(at least one) = 1 - P(none)`

------------------------------------------------------------------------

# 25. Statistics

### Mean

`Mean = Σx/n`

### Weighted Mean

`Weighted mean = Σwx/Σw`

### Median

Arrange data first.

-   Odd number of observations → middle observation.
-   Even number → average of two middle observations.

### Mode

Most frequently occurring value.

### Range

`Maximum - Minimum`

`Smaller angle = 360° - calculated angle`

### Important

# 28. Calendar

### Odd Days

-   Ordinary year = **1 odd day**
-   Leap year = **2 odd days**
-   7 days = 0 odd days

### Leap Year Rule

A year is a leap year if:

-   divisible by 4,
-   except century years must be divisible by 400.

Examples:

-   2024 → leap year
-   1900 → not leap year
-   2000 → leap year

### Trick

For day-of-week questions, reduce total days modulo 7.

# 29. Age Problems

### Basic Rule

Age difference remains constant.

If A is 5 years older than B:

`A-B = 5` always.

### Ratio Method

If present ages are in ratio `a:b`:

`A = ax, B = bx`

Use the given future/past condition to find `x`.

### Trick

For age questions, create a small timeline:

`Past → Present → Future`

Then add/subtract the same number of years from every person's age.

# 30. HCF and LCM Tricks

### Prime Factorization

HCF:

Take **minimum powers** of common prime factors.

LCM:

Take **maximum powers** of all prime factors.

### Fractions

For positive fractions:

`HCF of fractions = HCF(numerators) / LCM(denominators)`

`LCM of fractions = LCM(numerators) / HCF(denominators)`

# 31. Logarithms

### Basic Laws

-   `log(ab)=log a + log b`
-   `log(a/b)=log a - log b`
-   `log(a^n)=n log a`
-   `log_a a = 1`
-   `log_a 1 = 0`

### Change of Base

`log_a b = log_c b / log_c a`

### Common Values

-   `log 1 = 0`
-   `log 10 = 1`
-   `log 100 = 2`
-   `log 1000 = 3`

# 32. Progressions

## Arithmetic Progression (AP)

First term = `a`

Common difference = `d`

### nth Term

`aₙ = a+(n-1)d`

### Sum

`Sₙ = n/2[2a+(n-1)d]`

Also:

`Sₙ = n/2(a+l)`

where `l` is the last term.

## Geometric Progression (GP)

First term = `a`

Common ratio = `r`

### nth Term

`aₙ = ar^(n-1)`

### Sum of n Terms

`Sₙ = a(r^n-1)/(r-1)` for `r ≠ 1`

Alternative:

`Sₙ = a(1-r^n)/(1-r)`

`n(A∪B∪C) = n(A)+n(B)+n(C) - n(A∩B)-n(B∩C)-n(C∩A) + n(A∩B∩C)`

### Complement

`n(A') = n(U)-n(A)`

# 34. Coordinate Geometry

### Distance Between Two Points

For `(x₁,y₁)` and `(x₂,y₂)`:

`d = √[(x₂-x₁)²+(y₂-y₁)²]`

### Midpoint

`[(x₁+x₂)/2, (y₁+y₂)/2]`

### Slope

`m=(y₂-y₁)/(x₂-x₁)`

### Section Formula

Point dividing `(x₁,y₁)` and `(x₂,y₂)` internally in ratio `m:n`:

`[(mx₂+nx₁)/(m+n), (my₂+ny₁)/(m+n)]`

# 42. Exam Short Tricks --- High Priority

## Trick 1: Work Together

If A takes 10 days and B takes 15 days:

LCM = 30 work units.

-   A = 3 units/day
-   B = 2 units/day
-   Together = 5 units/day
-   Time = `30/5 = 6 days`

## Trick 2: Average Replacement

Average of 10 students = 50.

A student scoring 40 leaves and another scoring 60 joins.

Change = `60-40 = 20`

Average increase = `20/10 = 2`

New average = **52**

## Trick 3: Successive Percentage

+10% followed by +20%:

`10+20+(10×20)/100 = 32%`

## Trick 4: Profit

CP = ₹800, profit = 15%

`SP = 800×115/100 = ₹920`

## Trick 5: Equal Distance Average Speed

Speeds = 40 and 60 km/h:

`Average = 2×40×60/(40+60) = 48 km/h`

# 43. Common Exam Mistakes

1.  **Profit/Loss percentage is normally calculated on CP**, not SP.
2.  **Discount percentage is calculated on MP**, not CP.
3.  Convert **km/h ↔ m/s** before using distance in metres.
4.  In work problems, add **work rates**, not completion times.
5.  In pipes, an emptying pipe has a **negative rate**.
6.  In ratio questions, multiply/divide all terms by the same number.
7.  For percentage change, denominator is the **original value**.
8.  For average speed, do not blindly take the arithmetic mean.
9.  Check whether a probability question says **at least**, **at most**,
    or **exactly**.
10. In geometry, check whether the question asks for **area, perimeter,
